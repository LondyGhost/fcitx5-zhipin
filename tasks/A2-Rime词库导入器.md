# A2 — Rime 词库导入器

> 本任务完成后由统一集成验收负责人复核。请先阅读整体方案的 Rime 兼容要求、A0 字典/索引契约及独立任务验收标准。

## 目标与输入

开发离线工具，将明确支持的 Rime/rime-ice 词库文本格式转换为引擎索引。输入包括冻结的 `docs/interfaces/dictionary.md` 和索引格式契约、合法且最小化的词库样本及格式说明。不得假设旧路径/文件名；需核实真实格式。

## 输出与文件所有权

- `source/dict-importer/**`
- `tests/dict-importer/**`
- `docs/modules/rime-import.md`

不得修改 runtime dictionary、公共接口、完整原始词库或其他任务文件。

## 接口边界

命令行工具从显式参数读取输入，输出契约规定的版本化索引与导入报告。字段布局、排序/去重、错误退出码服从 A0 契约，供 A3 loader 消费。

## 硬性要求

- 记录支持的编码、BOM、注释、字段、权重、转义规则和格式子集。
- 不执行 Lua、Rime Processor 或词库中的任何代码。
- 对不支持语法和坏行明确报告，不能静默丢弃；报告有效、跳过、重复数量和定位信息。
- 相同输入确定性地产生相同输出；解析资源使用有界。
- 不把完整第三方词库提交进仓库；测试 fixture 最小化并说明来源/许可。

## 验收标准

- Golden tests 覆盖合法行、注释、转义、BOM、权重、重复、编码错误及不支持格式。
- 重复执行输出字节一致；坏输入有非零退出和可定位诊断。
- 生成索引可由 A3 loader 读取，交叉测试结果一致。
- 有 CLI 帮助、使用示例、格式限制和许可说明。
- 由统一验收负责人独立复跑并按 `docs/独立任务验收标准.md` 记录结论。

## 依赖与交付

A0 格式契约冻结后开始，可与 A1、A3、A4、A5 并行。交付提交号、接口/索引版本、 fixture 来源、测试命令和结果、已知限制。
