# A0 — 接口契约与构建骨架

> 本任务先于 A1–A5。请先阅读项目 README、整体方案、任务拆分和独立任务验收标准。

## 目标

为多人并行实现建立稳定的模块契约和可构建骨架。接口冻结是 A1–A5 正式开始集成实现的前置条件。

## 输入

- `docs/独立引擎整体方案.md`，特别是第 3、8 节。
- 目标 Linux 的 fcitx5、编译器和 CMake 版本信息。
- A1–A5 对核心类型、错误处理及构建入口的需求。

## 输出与文件所有权

- `docs/interfaces/**`
- `docs/目标机环境.md`
- 根 `CMakeLists.txt`
- `source/include/abc/**` 公共头文件
- 接口冒烟测试及必要的空模块构建清单

以上文件由 A0 单点维护；其他任务不可直接修改。A0 不拥有 A1–A5 模块实现文件。

## 接口边界

定义并文档化 `KeyCommand`、`EngineResult`、`Candidate`、`CandidateBatch`、`Dictionary`、session 工厂、索引格式版本、配置边界及 addon/core 依赖方向。接口至少表达按键是否消费、preedit、候选页和高亮、提交/清除等副作用，以及错误返回语义。

## 硬性要求

- 纯核心接口不依赖 fcitx5；核心不能反向依赖 addon。
- 字典接口只读；索引编码、排序、稳定 ID、分页语义明确。
- `EngineSession` 是缓冲唯一所有者，不允许 addon 再维护输入缓冲。
- 公共类型具有明确生命周期、线程约束和错误策略。
- 索引格式包含版本策略；向前/向后不兼容时必须明确报错。
- 根构建骨架能让模块独立加入，避免并行任务编辑同一构建文件。

## 验收标准

- 接口文档列出字段语义、生命周期、错误路径及调用示例。
- 下游 A1–A5 负责人确认契约；确认后标记版本并冻结。
- 干净 Linux 环境下 configure/build/test 冒烟通过。
- `docs/目标机环境.md` 有真实版本信息或明确标记待采集项，无凭据。
- 验收负责人按 `docs/独立任务验收标准.md` 独立复核。

## 依赖与并行

必须先于 A1–A5 接口集成。其他任务可并行调研或做不依赖公共头文件的私有原型；契约冻结后公共接口变更必须走集成负责人审批，并同步所有下游任务。

## 交付说明

提供提交号、接口版本、文件清单、干净构建命令/结果、已知待决项及下游确认记录。
