2. [`../docs/独立引擎整体方案.md`](../docs/独立引擎整体方案.md) — 整体设计与硬性要求
3. [`../docs/并行开发任务拆分.md`](../docs/并行开发任务拆分.md) — 任务关系、共享接口冻结和文件所有权
4. [`../docs/独立任务验收标准.md`](../docs/独立任务验收标准.md) — 统一验收要求
